Fallback 1: ready-made project folder

In Claude, open Projects → New project, click Use a folder and choose one of the folders below. Each folder already holds the instructions (CLAUDE.md), the system prompt and all knowledge files, and it is refreshed with every update. Put your own drafts in the folder's calismalar subfolder.

The folder paths appear here after setup.

If the assistant does not load its instructions

Occasionally the model starts answering the first question without calling the instructions tool. In that case click the + button next to the message box and choose the hukuk-burosu (Law Firm) or kurumsal (Corporate) prompt under arthurlegal-yerel, or do the project step above once.

Other components

  • Arthur Mask — Do not attach client documents to the chat directly; drop them into Arthur Mask first. On first start, print the recovery key and keep it safe.
  • ArthurLegal Tapu — Turkish land registry: type a parcel such as "İstanbul Kadıköy Caferağa 123 ada 45 parsel" or a place name in the chat. The parcel comes from the public data of TKGM Parsel Sorgu (one consent is asked at the first query). The {{URUN}} - Tapu shortcut on the desktop opens the same parcel tool in your browser. Land-registry record text never leaves this computer.
  • Project folders — The {{URUN}} - Project Folders shortcut in the Start menu opens the ready-made folders in File Explorer. If you drag files into a project by hand, that copy is not updated; the tools and "Use a folder" stay current.
  • Updates — Installed in the background. To check now, use {{URUN}} - Check for Updates in the Start menu.

Troubleshooting

If the tools do not appear, quit Claude Desktop completely, including the icon in the system tray, and open it again. Under Settings → Developer, arthurlegal-yerel, arthur-tapu and (if installed) arthur-mask should show as running. The first tool list also contacts the remote research server, so it can take a few seconds.
{{URUN}} is a legal research and drafting tool; it does not give legal advice. A lawyer must verify every output. Arthur Mask pseudonymises; it does not anonymise. The duty of confidentiality stays with the lawyer.
