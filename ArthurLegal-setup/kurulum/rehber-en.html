Installed packages

Law Firm — for lawyers: petitions, contracts, case-law and legislation research, deadlines. To list commands, type a plugin name such as /litigation-legal: in the chat, or simply describe the task.
Corporate Assistant — for in-house legal teams: contract review, compliance, data protection and company law. Describe the task; the assistant picks the steps itself.
Courthouse — neutral drafts for judges and court clerks (Turkish procedure). For example /hukuk-hakim:on-inceleme, /hukuk-kalem:tensip-zapti, /ceza-hakim:hukum-taslagi; for the reminders type "yarının duruşmaları" or "kesinleşme kontrolü". Do not attach case documents to the chat directly; drop them into Arthur Mask first. Every output is a draft for the judge or the panel to approve.
Academician — for legal academics: literature, citation checks, journal choice, publication ethics and grant applications. For example type /atif-kaynak: or /makale-yazim:. Confidential manuscripts and review material under evaluation are never given to the chat.

Other components

  • Arthur Mask — Do not attach client or case documents to the chat directly; drop them into Arthur Mask first. On first start, print the recovery key and keep it safe.
  • UYAP Dashboard — With Law Firm or Corporate and Arthur Mask, the {{URUN}} - UYAP Dashboard icon on the desktop opens the UYAP Lawyer Portal in a separate browser profile; you sign in with e-signature or e-Devlet. Open Tebligatlar (notifications) and Duruşmalarım (hearings), then press Tara (Scan). It is read-only: it writes nothing to UYAP and sends no extra requests; names and case numbers are masked by Arthur Mask before anything reaches Claude.
  • ArthurLegal Tapu — Turkish land registry: type a parcel such as "İstanbul Kadıköy Caferağa 123 ada 45 parsel" or a place name in the chat. The parcel comes from the public data of TKGM Parsel Sorgu (one consent is asked at the first query). The {{URUN}} - Tapu{{URUN}} Tapu icon on the desktop opens the same parcel tool in your browser. Land-registry record text never leaves this computer.
  • ArthurLegal Memory — The assistant keeps your preferences, corrections and a summary of the last session in a folder on this computer, so a new chat does not start from scratch. Say "remember this"; say "do not write to memory" and it will not, for that chat. Only masked text is written: ID numbers, IBANs, phone numbers and e-mail addresses are refused. {{URUN}} - Memory Folder in the Start menuMemory Folder in Applications > {{URUN}} opens the folder; edit the notes as you like.
  • Project folders — The {{URUN}} - Project Folders shortcut in the Start menu opens the ready-made folders in File Explorer.Project Folders in Applications > {{URUN}} opens the ready-made folders in Finder. If you drag files into a project by hand, that copy is not updated; the tools and "Use a folder" stay current.
  • Updates — Installed in the background. To check now, use {{URUN}} - Check for Updates in the Start menu.Check for Updates in Applications > {{URUN}}.
  • Uninstall — {{KALDIR}} in Applications > {{URUN}}.

Troubleshooting

If the tools do not appear, quit Claude Desktop completely, including the icon in the system tray, with Cmd+Q and open it again. Under Settings → Developer, arthurlegal-yerel and (if you chose them) arthur-tapu, arthur-mask and arthur-uyap should show as running. To add or remove modules, run the installer again. The first tool list also contacts the remote research server, so it can take a few seconds.
{{URUN}} is a legal research and drafting tool; it does not give legal advice and does not decide. The legal professional using it (lawyer, judge, court clerk or academic) must verify every output. Arthur Mask pseudonymises; it does not anonymise. The duty of confidentiality stays with the user.
