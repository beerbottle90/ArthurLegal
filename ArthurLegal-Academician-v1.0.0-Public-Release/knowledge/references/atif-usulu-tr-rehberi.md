# Türk Hukuk Atıf Usulü (Klasik Tam-Dipnot)

> ⚠️ **Derginin yazım kuralları her zaman üstündür.** Bu dosya yaygın teamülü anlatır;
> Türk hukuk dergileri arasında biçim farklılıkları vardır ve bazıları OSCOLA uyarlaması
> kullanır.

---

## Sistem

Kıta Avrupası kökenli **tam-dipnot** sistemi: metin içi atıf (Yazar, yıl) kullanılmaz;
her atıf sayfa altı dipnotta verilir; sonda kaynakça bulunur.

---

## İlk atıf kalıpları

**Kitap**
```
Yazar Soyadı, Adı: Eser Adı, Baskı, Yer Yıl, s. X.
```

**Makale**
```
Yazar Soyadı, Adı: "Makale Başlığı", Dergi Adı, C. X, S. Y, Yıl, s. Z.
```

**Kitap bölümü**
```
Yazar Soyadı, Adı: "Bölüm Başlığı", içinde: Editör (ed.), Eser Adı, Yer Yıl, s. X-Y.
```

**Mahkeme kararı**
```
Yargıtay 11. HD, E. 2023/1234, K. 2024/567, T. 12.03.2024.
```

**Kanun maddesi**
```
TBK m. 112.
```

## Mükerrer atıf

| Usul | Biçim |
|---|---|
| Klasik | `Yazar, age., s. 40.` / `Yazar, agm., s. 40.` |
| Kısa başlıkla | `Yazar, Eser Adı (kısa), s. 40.` |
| OSCOLA uyarlaması (bazı dergiler) | `Yazar (n 12) 40.` |

---

## Yapılmayanlar (klasik TR usulü)

- `supra`, `infra`, `op cit`, `loc cit`, `id` **kullanılmaz** (bunlar Bluebook/Anglo-Amerikan usulüdür)
- Kısaltmalarda genellikle nokta kullanılmaz (dergiye göre değişir)
- Birden çok esere atıfta ayırıcı **noktalı virgüldür**

---

## Kaynakça düzeni

Türk hukuk dergilerinde kaynakça genellikle türe göre ayrılır:

```
KAYNAKÇA
Kitaplar ve Monografiler
Makaleler
İçtihat
Mevzuat
Elektronik Kaynaklar
```

Bazı dergiler tek alfabetik liste ister.

---

## Elektronik kaynak

Erişim tarihi verilir:
```
Yazar: "Başlık", <URL> (Erişim tarihi: 09.07.2026).
```

MCP/veritabanından çekilmiş kaynaklarda bu paket ayrıca **provenans etiketi** kullanır:
`[Yargı MCP — Yargıtay 11. HD — E. 2023/1234 K. 2024/567 — 09.07.2026]`

Provenans etiketi **çalışma notudur**, yayımlanacak dipnota konmaz; doğrulamanın izini tutar.
